# Spec 02 · 图谱视觉风格（莫兰迪 + 酒红画布）

Date: 2026-10-22
Status: **Accepted / Implemented**（`e9fb5be`）
Input: 用户在预览图确认（4 个维度中 3 个选「当前推荐项」，配色给自定义指示）

## 用户确认结果

| 维度 | 决定 |
|------|------|
| 节点标签 | 重要节点才画（有连边/有命中/暂存/选中），截断 10 字加省略号 |
| 配色 | **自定义：莫兰迪色系 + 红色画布底色** |
| 边样式 | 实线 co + 虚线 tag（当前方案） |
| 视图交互 | 固定视图（自适应布局，不做缩放平移） |

## 色板定稿

| 元素 | 颜色 | 说明 |
|------|------|------|
| 画布底色 | `#8e5a5f` | 莫兰迪酒红 |
| fact 节点 | `#7f99ac` | 雾蓝 |
| decision 节点 | `#c9a37e` | 灰杏 |
| lesson 节点 | `#8fa88b` | 灰绿 |
| howto 节点 | `#ab9bab` | 藕紫 |
| co 边 | `#e8d3c6` 实线 | 奶油白：红底上亮且柔；权重越大越粗 |
| tag 边 | `rgba(58,42,44,.55)` 虚线 | 暗灰红：退后不抢戏 |
| 选中描边 | `#f5ece7` | 亮奶油白圈 |
| 隔离页填充 | `#4d4348` | 深灰紫：警示红在红底上隐身，隔离语义由抽屉文字承载 |

## 实现约束

- 色值集中在 `client/client.js` 顶部 `GCOLOR / GEDGE / GBG` 三个常量，一处改全图生效。
- 刻意**不走 `--dsw-*` 主题 token**：这张图要有自己的性格；跟主题换色会破坏红底对比度。
- 边透明度按 weight 分三档（0.95 / 0.7 / 0.45），与选中节点无关的边压到 0.12。
